# PROTOTYP 3D - Sistema de Gestión Financiera PWA

Aplicación web progresiva (PWA) para gestión financiera de un negocio de impresión 3D.

## Usuarios
- **Mateo** — Administrador
- **Martina** — Administrador
- Contraseña: `Prototype3D`

## Tecnologías
- HTML, CSS (Tailwind CSS), JavaScript Vanilla
- PWA (Service Worker + manifest.json)
- Material Symbols, Space Grotesk, JetBrains Mono

## Módulos
- Dashboard (balance, actividad reciente, gráficos)
- Ingresos (registro, categorías)
- Gastos y Stock (desglose técnico, alertas)
- Estado de Resultados (tabla Q3 vs Q2)
- Flujo de Caja (proyección 7D/30D/90D)

## Instalación local

```bash
# Servidor local
python -m http.server 3000
# Acceder en http://localhost:3000
```
